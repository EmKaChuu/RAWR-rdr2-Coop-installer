# RAWR – RedDead Advanced Web Relay

Co-op do RDR2 przez P2P.

Fabuła Red Dead Redemption 2 ze znajomymi, bez przekierowania portów i bez publicznego IP
(działa też za CGNAT, np. UPC/Play). Dołączanie kodem zaproszenia.

## Pobierz

**[⬇ RAWR-Coop-Windows.zip](https://github.com/EmKaChuu/RAWR-rdr2-Coop-installer/raw/main/RAWR-Coop-Windows.zip)** — RAWR 0.2 beta (Windows, ok. 37 MB)

1. Rozpakuj zip (nie do folderu gry) i uruchom `RDR2CoopSetup.exe`.
   Windows może ostrzec, że aplikacja nie jest podpisana: „Więcej informacji” → „Uruchom mimo to”.
2. Wybierz klawisz menu (domyślnie **Numpad /**, drugi **Delete**) i kliknij „Zainstaluj”.
   Obaj gracze muszą mieć tę samą wersję.
3. Uruchom grę i wczytaj zapis fabuły. Każda gra hostuje własną sesję z nowym kodem przy każdym starcie.
4. **Host:** menu RAWR → *Session* → *Your invite code* (kod też w `scripts\RDR2Coop-invite.txt`).
   **Gość:** menu RAWR → *Session* → *Join by invite code* i wpisz kod od hosta.

Insert przeładowuje moda. *Tools → Pack my logs* pakuje wszystkie logi do zipa na Pulpicie.

## Skąd to jest

RAWR to nieoficjalna przeróbka moda [RDR2 Co-op](https://github.com/BigCheeseThe3st/rdr2-coop)
(GPL-3.0, plik `LICENSE`). Nie jest to projekt Rockstar Games ani autora oryginalnego moda.

## English

Download the zip above, run `RDR2CoopSetup.exe`, pick the menu key (Numpad / by default) and install.
In game open the RAWR menu: the host gives friends the code from *Session → Your invite code*,
friends use *Session → Join by invite code*. No port forwarding needed.
